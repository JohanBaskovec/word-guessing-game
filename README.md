# Jeu de mots coopératif (nom à définir)

Un petit jeu de mots **coopératif** pour **2 à 99 joueurs (ou plus)** qui se passent **un seul téléphone**.
Les joueurs sont répartis en deux équipes, **A** et **B**, et chaque équipe doit faire deviner ses mots secrets à l'autre.
Tout le monde gagne ensemble… ou perd ensemble.

- Fonctionne **entièrement hors ligne**.
- **HTML + JavaScript (+ CSS)** uniquement : aucun framework, aucun moteur de jeu, aucune dépendance, aucune étape de compilation.
- Pensé pour un téléphone tenu **en mode portrait**.
